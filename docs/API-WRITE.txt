POST /api/write/discovery-marks

Markeert een kaart als interessant of verwijdert die markering. Slaat uitsluitend een stabiele kaartidentiteit en naam op in discovery_marks in de primaire gebruikersdatabase. Vereist geen geïmporteerde catalogus, maakt geen collectie-/wanted-item aan en wijzigt de MTGJSON-catalogus niet. Herhalen met dezelfde gewenste marked-waarde is veilig.

INPUT JSON

{"name":"Voorbeeldkaart","scryfallOracleId":"11111111-1111-4111-8111-111111111111","marked":true}

name is verplicht en bevat na trimmen 1 tot 300 tekens. marked is verplicht en moet de JSON-boolean true of false zijn. scryfallOracleId is optioneel (null of leeg is toegestaan); indien aanwezig moet het een UUID zijn. Gebruik de naam en scryfallOracleId uit het cataloguszoekresultaat. Ongeldige invoer geeft HTTP 400.

OUTPUT JSON

{"data":{"markKey":"oracle:11111111-1111-4111-8111-111111111111","name":"Voorbeeldkaart","scryfallOracleId":"11111111-1111-4111-8111-111111111111","marked":true}}

HTTP 200 bij opslaan en verwijderen. Stuur marked=false voor verwijderen; de response bevat dan marked=false. Zonder Oracle-ID wordt de genormaliseerde naam als fallback gebruikt (markKey=name:<naam>). Een expliciet Oracle-ID kan een bestaande naammarkering vervangen. Verwijderen met een Oracle-ID laat andere bekende Oracle-ID's intact; verwijderen zonder ID verwijdert alle naamaliassen die deze naamkaart als gemarkeerd laten verschijnen. Markeringen worden via GET /api/read/discovery-marks gelezen en via marked=1 op cataloguszoeken en filteropties toegepast. De gebruikelijke toegangsbescherming van de write-API geldt ook hier.

POST /api/write/collection/import/preview

Controleert een kaartenlijst en toont de fysieke printings die zouden worden gebruikt, zonder collectieregels toe te voegen. Ondersteunt onder meer 1 Card Name, 1x Card Name, 1 Card Name (SET) 123, koppen zoals Commander, Main, Main Deck en Deck, *F* als foilmarkering en *E* als etched-markering. Setcode, kaartnummer, kaartnaam en taal moeten bij dezelfde paper-printing horen; officiële alternatieve namen zoals Godzilla-printings worden ook herkend. Regels zonder set en kaartnummer gebruiken een automatisch gekozen printing en krijgen inferredPrinting=true; voor een niet-Engelse taal zijn setcode en kaartnummer verplicht. Gebruik expliciet 1x bij een kaartnaam die met een getal begint wanneer die regel anders dubbelzinnig kan zijn.

INPUT JSON

{
  "text": "Commander\n1 Sol Ring (CMM) 396\n\nDeck\n10 Forest (CMM) 450\n1 Command Tower (CMM) 995 *F*",
  "finish": "nonfoil",
  "language": "en",
  "condition": "near_mint",
  "location": "Precon-doos",
  "notes": "Complete listing",
  "reconcileWanted": true
}

OUTPUT JSON

{
  "data": {
    "canImport": true,
    "previewToken": "64-tekens-sha256-token",
    "items": [
      {"line":2,"cardId":123,"name":"Sol Ring","setCode":"cmm","collectorNumber":"396","quantity":1,"finish":"nonfoil","language":"en","inferredPrinting":false,"warning":""}
    ],
    "failures": [],
    "summary": {"rows":3,"resolvedRows":3,"quantity":12,"failureCount":0,"inferredPrintings":0}
  }
}

POST /api/write/collection/import

Voegt dezelfde volledig geldige kaartenlijst atomair toe. Stuur de previewToken uit de direct voorafgaande controle mee. Bij één parse-, kaart- of afwerkingsfout wordt niets aan de collectie toegevoegd en volgt status 422 met de preview en fouten onder error.details. Als de opgeloste printings na de controle zijn gewijzigd, volgt status 409 met een nieuwe preview onder error.details.

INPUT JSON

Gebruik dezelfde invoer als bij /api/write/collection/import/preview en voeg toe:

{"previewToken":"64-tekens-sha256-token"}

  "data": {

    "importedQuantity": 12,
    "imported": [
      {"id":55,"cardId":123,"name":"Sol Ring","setCode":"cmm","collectorNumber":"396","quantity":1,"finish":"nonfoil","sourceLines":[2]}

    "summary": {"rows":3,"resolvedRows":3,"quantity":12,"failureCount":0,"inferredPrintings":0,"importedRows":3,"importedQuantity":12,"collectionItems":3}
  }
}

POST /api/write/decks/:id/cards

Voegt een kaart toe aan een deck. Voeg één kaartidentificatie toe. Rollen: commander, partner, companion, main, sideboard, maybeboard.

Kaarten ontdekken gebruikt hetzelfde endpoint met name voor een kaart die nog geen lokaal cardId heeft. De server kiest een lokaal bekende printing of haalt die via de exacte Scryfall-naam op. Er wordt geen fysiek exemplaar aan de collectie toegevoegd. Optioneel expectedOracleId (UUID) controleert of de opgeloste printing hetzelfde Oracle-kaartconcept heeft; een afwijking geeft HTTP 409 vóór de decktoevoeging, ongeldige invoer HTTP 400. Bestaande aanroepen zonder dit veld blijven ongewijzigd.

INPUT JSON

{"scryfallId":"uuid","quantity":1,"role":"main","note":"","tags":["Ramp","Sacrifice"]}

OUTPUT JSON

{
  "data": {
    "id": 77,
    "quantity": 1,
    "role": "main",
    "note": "",
    "tags": ["Ramp","Sacrifice"],
    "coverage": {},
    "card": {"id":123,"name":"Eternal Witness","usage":{},"insights":{}}
  }
}

POST /api/write/maintenance/card-catalog/import

Start op de achtergrond een import van de officiële MTGJSON AtomicCards-catalogus en antwoordt direct met HTTP 202. Er kan maar één import tegelijk actief zijn; een tweede start antwoordt met HTTP 409 en foutmelding "Er wordt al een MTGJSON-kaartcatalogus geïmporteerd.". De downloadbron is vastgezet op de officiële MTGJSON HTTPS-URL en kan niet via dit request worden gewijzigd.

De import schrijft eerst een tijdelijke, zelfstandige SQLite-database en activeert die alleen na controle. De primaire gebruikersdatabase, het 2.0-schema en collectie-, deck- en wantedgegevens worden niet gewijzigd en bevatten geen verwijzing naar deze catalogus. Een bestaande catalogus blijft tijdens de import en bij een mislukking beschikbaar.

Lees voortgang en het eindresultaat via GET /api/read/card-catalog/status. Mogelijke statuswaarden zijn running, completed en failed; phase beschrijft onder meer checking, downloading, verifying, parsing, indexing, activating, complete of failed.

INPUT JSON

{}

OUTPUT JSON - HTTP 202

{
  "data": {
    "id": "uuid",
    "status": "running",
    "phase": "checking",
    "processed": 0,
    "total": null,
    "downloadedBytes": 0,
    "totalBytes": null,
    "message": "Import wordt voorbereid…",
    "startedAt": "2026-10-03T06:25:00.000Z",
    "finishedAt": null
  }
}

OUTPUT JSON - HTTP 409

{"error":{"message":"Er wordt al een MTGJSON-kaartcatalogus geïmporteerd."}}
